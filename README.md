# Prática de Programação Estruturada

Este repositório reúne exercícios desenvolvidos na disciplina **Prática de Programação Estruturada**, cursada no **1º período na FMP — Faculdade Municipal de Palhoça**.

O objetivo é registrar a evolução acadêmica no estudo de algoritmos e programação em Python, mantendo os exercícios organizados para consulta, revisão e apresentação no GitHub.

## Conteúdos Praticados

- Entrada e saída de dados.
- Variáveis e operadores.
- Estruturas condicionais.
- Estruturas de repetição `for` e `while`.
- Manipulação básica de strings.
- Listas.
- Desenvolvimento de algoritmos.

## Tecnologia Utilizada

- Python 3

## Atividade AV3

O arquivo `av3/luanpereira_opcao1.py` contém um sistema simples de pedidos para uma lanchonete. O exercício permite adicionar itens do cardápio, remover itens, visualizar o resumo do pedido, calcular subtotais e confirmar ou cancelar o pedido.

## Como Executar no Windows

Antes de executar os exercícios, tenha o **Python 3** instalado no computador.

Clone o repositório:

```powershell
git clone https://github.com/LuanPereiradaCosta/pratica-programacao-estruturada.git
```

Acesse a pasta do projeto:

```powershell
cd pratica-programacao-estruturada
```

Execute um exercício informando o caminho do arquivo:

```powershell
python caminho/do/arquivo.py
```

Exemplo:

```powershell
python av3/luanpereira_opcao1.py
```

## Aprendizados

Durante a disciplina, os exercícios ajudaram a praticar a construção de algoritmos simples, o uso de entrada e saída de dados, a aplicação de condições, repetições e listas, além da organização gradual do raciocínio lógico necessário para resolver problemas com Python.
